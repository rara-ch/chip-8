# CHIP-8 Interpretor

A CHIP-8 emulator written in Go.

This project is an implementation of the CHIP-8 virtual machine, built to explore low-level programming concepts including instruction decoding, memory management, registers, the fetch-decode-execute cycle, and emulation.

The motivation for this project is to deepen my understanding of the concepts I learn in the NAND2Tetris course.
